# 速读训练 · 视野优先

纯前端单文件阅读训练器：舒尔特方格、周边视野、逐词快闪、节奏逐行、读后测验。无账号、无后端、成绩只存在本机浏览器。

## 本地打开

直接双击 `index.html` 即可。训练功能完整可用；实验室的镜头追踪需要 HTTPS 或本地地址（`file://` 下浏览器不允许取摄像头）。

本地起服务：

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/index.html
```

## 实验室

顶栏「实验室」是研发验证页：实时显示 MediaPipe 的人脸关键点、头部姿态、眼位、帧率与推论耗时，可记录 30 秒并导出 JSON。它不参与训练、不写成绩，画面只在本机处理。

## 说明

- 训练目标是「视野广度 + 专注 + 理解」，不以 WPM 为成就指标。
- 不做线型／S 型／圆形扫视关卡，不宣称视力疗效。
